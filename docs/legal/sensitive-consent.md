# 要配慮個人情報の取得への同意

版：2026-09-26

> これは下書きです。【要記入】【要確認】は運営者が決める箇所です。
> 公開する前に、必ず専門家（弁護士など）に確認してもらってください。
>
> このファイルは app/src/legal/documents.ts から作っています。直すときはそちらを直し、
> `cd app && npm run legal:docs` で作り直してください。

## 要点

- 「読んでもらう側」として登録すると、あなたに見えにくさがある可能性を示す情報を、運営者が持つことになります。
- この情報は法律で特に慎重に扱うよう定められているため、同意をいただいてから取得します。
- 使うのは、読んでくれる人とつなぐためと、不正な使い方を防ぐためだけです。第三者には提供しません。
- 同意しない場合、読んでもらう側では登録できません（読む側で登録することはできます）。

## 同意いただく内容

【要記入：事業者名】は、あなたが本サービスに「読んでもらう側（依頼者）」として登録したことを記録します。この記録は、あなたに視覚の障害がある、または見えにくさがある可能性を示すため、個人情報保護法の「要配慮個人情報」に当たる可能性があります。

運営者は、この情報を、読み上げのボランティアとつなぐため、および不正な使い方を防ぐためだけに使い、第三者には提供しません。

退会すると、この情報を消します。

同意しない場合は、依頼者として登録できません。ボランティアとして登録することはできます。
